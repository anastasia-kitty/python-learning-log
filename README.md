# Python Learning Log

A daily record of my Python practice, data structures and algorithms, and English writing.

I am learning Python step by step. This repository is where I keep small exercises, notes, and reflections. I write the README, code comments, and daily notes in English so I can practice technical English at the same time.

## Why this repository

- To practice Python for at least 15 minutes every day.
- To build a visible record of my progress.
- To get more comfortable with data structures and algorithms.
- To write and explain code in English.
- To make consistency easier than perfection.

## Goals

1. Solve or review one small problem on most days.
2. Write a short note in English for every practice session.
3. Run the code before committing it.
4. Review old problems once a week.
5. Keep going after a missed day instead of starting over.

I will add more topics and folders as the log grows. I do not need a perfect structure on day one.

## Daily routine

1. Pick one small problem or one review topic.
2. Create a folder for the date, for example `2026/11/04/`.
3. Write the solution in a `.py` file.
4. Add clear English comments and a short docstring.
5. Run the code and check a few examples.
6. Fill in `notes.md` using `TEMPLATE.md`.
7. Update `PROGRESS.md`.
8. Commit and push.

## English practice

I use simple English first, then improve it.

- I write comments that explain **why**, not only **what**.
- I keep new words in [VOCABULARY.md](VOCABULARY.md).
- I ask for grammar corrections when a sentence feels awkward.
- I do not let a grammar mistake stop me from committing.

## Consistency rules

- The minimum session is 15 minutes.
- A review day or a notes-only day still counts.
- A missed day is not a failure. The next day is a new entry.
- I commit real work, not empty changes just to keep a streak.
- The green squares are a side effect, not the goal.
